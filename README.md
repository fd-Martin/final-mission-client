# 📚 Book Courier

A modern book delivery and management platform built with React and Vite, designed to provide a seamless experience for readers, librarians, and administrators.

## 🌐 Live Demo

🔗 **Live Site:** https://final-mission-24a14.web.app

---

## ✨ Features

- Secure Authentication & Authorization
- Browse and Search Books
- View Book Details
- Add Books to Wishlist
- Order Books & Online Payment Integration
- Track Order Status
- Submit Reviews After Successful Purchase
- Role-Based Dashboard (User, Librarian & Admin)
- Fully Responsive Design

---

## 🔐 Authentication

Users can register with:

- Name
- Profile Image
- Email
- Password

After registration, every user is assigned the **User** role by default.

Registered users can securely log in using their email and password.

---

## 📖 Public Access

The following pages are available without login:

- Home Page
- All Books Page

### Search Functionality

Users can search books by title from the **All Books** page.

### Protected Routes

Users must be authenticated to access:

- Book Details
- Dashboard

---

## 👤 User Role

### User Features

- Browse Books
- View Book Details
- Add Books to Wishlist
- Order Books
- Make Payments
- Track Orders
- Submit Reviews

### User Dashboard

- 📦 My Orders
- 🧾 Invoice History
- ❤️ Wishlist
- 👤 My Profile

---

## 📚 Librarian Role

### Requirements

A Librarian must:

- Be an authenticated user
- Be approved by an Admin

### Librarian Features

- Add New Books
- Edit Existing Books
- View Added Books
- Manage Orders for Their Books

> Librarians cannot delete books.

### Librarian Dashboard

- ➕ Add Book
- 📚 My Books
- 📦 Orders
- 👤 My Profile

---

## 👑 Admin Role

### Admin Features

- Manage All Users
- Assign Roles (User → Librarian/Admin)
- Publish Books
- Unpublish Books
- Manage Platform Content

### Admin Dashboard

- 👥 Manage Users
- 🔄 Manage Roles
- 📚 Manage Books
- ⚙️ Platform Control
